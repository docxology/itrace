# iTrace v0.5.0

iTrace v0.5.0 improves the correctness and reproducibility of the MIT-licensed
toolkit at <https://github.com/docxology/itrace>.

## Changes

- Includes the unreleased AOI dwell/transition statistics, regularized polynomial
  calibration, and visible live-calibration target cues already in `main`.
- Recording streams own read-only float64 arrays; subsequent caller mutations
  cannot alter an analysis. Callers that edited stream arrays in place must
  construct a new stream.
- Velocity uses actual timestamps on irregular recordings. Nonfinite gaze and
  velocity samples split events rather than becoming fixations or bridging gaps.
- Pupil interpolation uses elapsed time. Short-trace filtering preserves length
  and constants, configured smoothing windows take effect, zero-MAD outliers are
  rejected, and traces without interpolation anchors fail explicitly.
- Configuration, CSV pupil units, and exported report counts/durations are
  validated. Previously accepted invalid inputs can now raise `ValueError`.
- Live exports retain the displayed detector settings; plots use the effective
  threshold, including a valid zero threshold. API version follows package version.
- Manuscript builds stage four formats, reject unresolved references, retain
  failure intermediates, and preserve reader artifacts on render failure.
- Core-only and development CI, installed-wheel smoke checks, source/runtime
  receipts, release metadata checks, figure hashes, and asset inventories make
  releases verifiable. Dates and DOI metadata are synchronized with this version.

## Evidence

Current test, coverage, and runtime results are recorded in
[`../verification_metrics.json`](../verification_metrics.json). Figures are
inventoried in [`../figure_manifest.json`](../figure_manifest.json). The source
archive, wheel, source distribution, manuscript PDF, verification ledger, figure
manifest, empirical summary ledgers, release notes, license, and citation are
published together with `SHA256SUMS` and a commit-bound `release-manifest.json`.

The first hosted run exposed styled-help assertions and a missing output
directory in the optional figure smoke command. Both failures were reproduced
locally and corrected. Help assertions now exercise plain and forced-color
output using standard-library text handling; the option assertions are retained.
The failed run remains available alongside the successor run's release evidence.
The Python 3.10 lane also exposed exception-dependent synthetic dropout
preprocessing. Synthetic-domain runs now select preprocessing from finite-input
masks before analysis, and the regression requires every dropout run to report
its actual preprocessing. Clean runs retain their unmodified input path.

## Limits

The empirical figures reuse historical summary ledgers from the five-session,
single-participant, single-device diagnostic pilot. This release adds no new
participant or reference-device evidence and makes no reference-device accuracy,
cross-device generality, population generality, or webcam-accuracy validation
claim. The full pupil preprocessing pipeline uses surrounding samples; only the
standalone phase classifier has a causal guarantee.

The Python 3.10 SciPy native import failure on the local macOS host is preserved
in the development review. Linux support is assessed separately by hosted CI.
See [`../COMPREHENSIVE_REVIEW.md`](../COMPREHENSIVE_REVIEW.md) for provenance and
the disclosed initial overwrite of the ignored development `.coverage` file.
